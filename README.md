# 🎁 Regalo de cumpleaños (HTML + CSS + JS)

Sitio estático: no necesita PHP, servidor ni internet. Fuentes e ilustraciones están incluidas.

## Ver en tu computadora
Abre `index.html` con doble clic (o con la extensión Live Server de VS Code).

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube **el contenido de esta carpeta** (`index.html`, `css/`, `js/`, `img/`, `fonts/`, `audio/`) a la raíz.
2. En el repositorio: **Settings → Pages → Build and deployment**.
3. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y pulsa **Save**.
4. Espera 1–2 minutos: tu página quedará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

> Si el repositorio es público, cualquiera con el enlace podrá ver las fotos y la carta. Considera no compartir el enlace con nadie más.

## Música (opcional)
Guarda una canción con el nombre exacto **`audio/musica.mp3`**. Los botones de música aparecen solos; sin el archivo no se muestran. Empieza solo cuando ella pulsa un botón.

## Editar textos
- La carta, frases y mensajes están en `index.html` (busca el texto y cámbialo).
- Estilos: `css/estilos.css` · Interacciones: `js/animaciones.js`.
- Las fotos `img/amor1.jpg … amor6.jpg` no se modificaron.
